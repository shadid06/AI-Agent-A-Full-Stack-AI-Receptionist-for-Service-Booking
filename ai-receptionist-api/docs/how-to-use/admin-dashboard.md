# Admin Dashboard

## Status

Planned.

## Purpose

The admin dashboard will be the business operator UI for onboarding, configuration, booking oversight, and analytics.

## Planned screens

- onboarding
- business profile
- services
- staff
- bookings
- conversations
- notifications
- billing
- usage

## Notes

- This is intentionally planned after the backend foundation.
- The dashboard should use the authenticated business workspace and never raw public tenant IDs.
