# Notifications

## Status

Planned.

## Purpose

Notifications will send booking confirmations, reminders, reschedules, and cancellations through email, SMS, and WhatsApp.

## Expected channels

- Email
- SMS
- WhatsApp

## Planned use

1. Trigger a notification when a booking is created or updated.
2. Send reminders before the booking starts.
3. Notify staff when changes happen.
4. Record notification status for auditability.

## Notes

- This module is not implemented yet.
- The recommended backend design is event-driven.
