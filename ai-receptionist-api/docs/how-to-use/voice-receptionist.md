# Voice Receptionist

## Status

Planned.

## Purpose

Voice mode will let customers speak to the receptionist instead of typing.

## Planned channels

- browser voice
- live call handling
- speech-to-text
- text-to-speech

## Planned use

1. Capture customer speech.
2. Transcribe the message.
3. Route it through the AI agent.
4. Speak back the response.

## Notes

- Voice should reuse the same booking and guardrail logic as chat.
- All voice actions must still resolve against the same business context.
